A single out-of-office email auto-reply of at most 200 characters — painfully honest about the sender's absence and inbox, and still polite enough that a manager would let it stand — written by `main.py` for make.fun's "The Painfully Honest Out-of-Office" bounty.

The entry: *"I'm away this week, and honestly your email is joining the 214 unread messages I'm quietly avoiding — thank you for writing, and I'll reply properly once I'm back and brave enough to open my inbox."* (197 characters, one sentence.)

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 -P -s main.py
cat /tmp/out/entry.txt
```
